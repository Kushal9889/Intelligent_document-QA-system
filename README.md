# Agent (project)

Short description

This repository contains a small Python project. It uses a local virtual environment in `env/`.

How to run

1. Activate the virtual environment (macOS / Linux zsh):

```bash
source env/bin/activate
```

2. Install dependencies (if needed):

```bash
pip install -r requirements.txt
```

3. Run the main script:

```bash
python main.py
```
